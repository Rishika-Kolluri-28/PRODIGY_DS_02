# Prodigy InfoTech – Data Science Internship

## Task 02: Data Cleaning and Exploratory Data Analysis (EDA)

### 1. Objective
The objective of this task is to perform data cleaning and Exploratory Data Analysis (EDA) on the Titanic dataset. The analysis helps identify relationships, patterns, and trends among passengers.

### 2. Dataset
- Dataset: Titanic Dataset
- Total Records: 891 passengers
- Original Columns: 12
- Source: Prodigy InfoTech GitHub Dataset

### 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

### 4. Data Cleaning
The following data cleaning operations were performed:
- Handled missing Age values using the median.
- Handled missing Embarked values using the mode.
- Replaced missing Cabin values with "Unknown".
- Created a Has_Cabin column.
- Created a FamilySize column.
- Created an IsAlone column.
- Checked missing values after cleaning.

### 5. Exploratory Data Analysis (EDA)
The following visualizations were created:
1. Survival Count
2. Survival by Gender
3. Survival by Passenger Class
4. Age Distribution
5. Fare Distribution by Passenger Class
6. Correlation Heatmap

### 6. Project Outputs
The outputs folder contains:
- Cleaned Titanic dataset.
- Survival count chart.
- Survival by gender chart.
- Survival by passenger class chart.
- Age distribution chart.
- Fare distribution chart.
- Correlation heatmap.

### 7. How to Run the Project

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the Python program:

```bash
python task2.py
```

### 8. Conclusion
This project demonstrates data cleaning and exploratory data analysis using Python. It helps understand passenger survival patterns and relationships between different variables in the Titanic dataset.
